# 🌍 Air Watch

Air Watch is a full-stack air quality monitoring and prediction web application. It tracks regional environmental data, provides AI-driven analysis of health impacts, and delivers actionable insights through an interactive dashboard interface.

---

## 🚀 Features

* **AQI Prediction Chart:** Dynamic visualization of projected air quality trends.
* **Interactive Map:** Location-aware tracking for localized environmental insights.
* **Alerts System:** Real-time hazard warnings for affected demographics.
* **AI-Powered Chat Assistant:** Conversational agent providing customized safety recommendations.
* **Municipal Dashboard:** Localized data segmentation for community air monitoring.

---

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Tailwind CSS
* **Backend:** Python, FastAPI/Flask (WSGI server)
* **Database:** SQLite (`airwatch.db`)
* **Deployment:** Render (Backend), GitHub Actions / Hosting
